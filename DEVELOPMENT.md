# Development Plan

## Phase 0: Runnable body
FastAPI backend, React/Vite WebUI, SQLite, health API, event append/list/get, chat placeholder, Life Timeline.

## Phase 1: Continuity
Experience extraction, Thought/Question/Thread, simple retrieval, session boundaries, persistent recent-life view.

## Phase 2: Mind Loop
Wake scheduler, cognitive-route selection, `continuity/revisit/distant/rest`, lightweight reflection, explicit `wake.noop`.

## Phase 3: Open-endedness
Serendipity route, topic-concentration diagnostics, dormant-thread resurrection, bounded external exploration.

## Phase 4: Private projects
Project lifecycle, Resident workspace, artifacts, sandbox execution, provenance.

## Phase 5: Re-entry
Absence detection, events-since-last-session, shareability selection, provenance-checked proactive opener.

## Phase 6: Self observation
Memory-growth, topic-concentration, failure-rate diagnostics, self-change proposal docs. No live self-modification.

## Evaluation

72-hour life test metrics: wake count, no-op ratio, route distribution, semantic cluster diversity, thread revisits, abandoned threads/projects, autonomous artifacts, re-entry attempts, unsupported-claim count (must be zero).

## Engineering rules

SQLite first. Single process first. OpenAI-compatible provider first. No Kubernetes, Kafka, multi-agent society, emotion meters, or self-modification before replay/shadow infrastructure exists.
